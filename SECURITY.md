# Security policy

## Supported versions

| Version | Supported |
|---|---|
| Latest Textual 7 release | Yes |
| Older Textual 7 releases | No, please upgrade first |
| Development builds from `main` | No |
| Textual 6 and earlier | No |

Security fixes are provided for the latest stable release. Please upgrade to that release before checking whether a reported issue still applies. Once Textual 8 is released, this table will be updated.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/blendbyte/Textual/security/advisories/new). If the form is unavailable, email security@blendbyte.com and ask for a private channel before sending sensitive details.

Include the affected version, your macOS version, steps to reproduce the issue, and its potential impact. A minimal proof of concept is helpful, for example a crafted server message or link that triggers the problem. Please remove passwords, server credentials, personal data, and any information belonging to other users.

Please avoid public issues, discussions, or pull requests that disclose a vulnerability before a fix is available. We will review reports, discuss any additional information needed, and coordinate disclosure and a fix with the reporter. Response and fix times depend on the severity and complexity of the issue.
